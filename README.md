# AI Security Lab

> A public repository documenting my transition from Software Engineering into AI Security through structured research and hands-on experiments.

## About

As frontier AI systems become increasingly capable, understanding how to build secure and trustworthy AI is becoming just as important as building intelligent AI.

This repository documents my self-directed journey into AI Security. My goal is to strengthen my understanding of large language models (LLMs), AI safety, prompt injection, AI agents, and security mechanisms through practical experiments, technical research, and continuous learning.

## Objectives

- Build a strong foundation in AI Security.
- Explore real-world security challenges in modern AI systems.
- Document experiments and technical observations.
- Learn responsible approaches to attacking and defending AI systems.
- Develop the skills required to contribute to secure frontier AI.
